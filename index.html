O que é o Synapse

Uma biblioteca de capacidades para o agente, com limites escritos

O agente de IA faz melhor quando segue um procedimento e erra menos quando há uma trava fora do modelo. O Synapse entrega as duas coisas: procedimentos em skills e travas em hooks.

Skill

Uma pasta com um SKILL.md que ensina o agente a fazer uma tarefa: como entrevistar, como redigir, onde cada código vive.

Plugin

Um pacote de skills com hooks ou servidor MCP. O guardrails é o exemplo: bloqueia a escrita em rastreador mesmo que o agente peça.

Rascunho local

Os plugins de planejamento gravam arquivos na sua máquina e param aí. Quem publica issue ou documento é você, depois de ler.
